Quick3D Viewer

3D CAD Viewing, Made Simple.

A 3D CAD viewer for iPhone, developed by Moriki Engineering. View STEP models, inspect parts and check dimensions wherever you work.

Inspect shapes and dimensions on your iPhone

Review STEP models on the shop floor, in meetings or while away from your desk. Open a file, move the model with touch gestures, and inspect parts and dimensions.

About the current release

Quick3D Viewer expands on QuickSTEP Viewer with support for more file formats. As of October 15, 2026, the App Store lists QuickSTEP Viewer v1.0 with STEP/STP support. Current release features and development work for a future version are described separately below.

Features in the current release

Open and explore

View STEP/STP models and rotate, zoom and pan with touch gestures. Inspect model colors and XYZ orientation, and choose a background theme.

Inspect individual parts

Select parts from the model tree and show or hide them individually to find the area you want to inspect within an assembly.

Check dimensions

Measure two-point distances and XYZ differences, cylinder diameters and radii, and distances between parallel faces. Available measurements depend on the model geometry and how it is recognized.

File formats in the current release

STEP / STP (.step / .stp)

These are the formats listed for v1.0 on the App Store. See the development section below for IGES and mesh formats.

In development for a future version

Importers for the formats below are implemented in the development version. App Store availability has not been confirmed, and on-device viewing and interaction checks remain. These formats are not listed as supported by the current v1.0 release. No release date has been set.

IGES / IGS
Import of .iges / .igs CAD files.
STL / OBJ / PLY
Triangle mesh viewing: no color for STL, basic colors for OBJ and vertex colors for PLY. Point clouds are not supported.
3MF
Core meshes, component placements and basic colors. Extensions and textures are not supported.
GLB / glTF
Static glTF 2.0 triangle meshes, hierarchy and basic colors. Textures, animation playback and compression extensions are not supported.
USDZ / USD
Readable static triangle meshes only, rather than full USD scene composition. Binary USD and complex USDZ files have not been verified with real-world data.

Measurement and display limitations

Mesh formats do not support CAD-specific diameter, radius, face-distance or axis-distance measurements. STL, OBJ and PLY units are assumed to be millimeters. Two-point measurement is also disabled when USD units cannot be confirmed. Textures and transparency are not supported.
