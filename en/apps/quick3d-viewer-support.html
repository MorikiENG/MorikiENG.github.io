Quick3D Viewer

Support

Help with Quick3D Viewer operations, display issues and bug reports. The app was formerly named QuickSTEP Viewer.

If you need help

  • If a file will not open, check the supported formats and confirm the file has finished downloading to your device.
  • For questions about display or controls, tell us your app version and the steps that led to the issue.
  • Check important CAD geometry and dimensions against the original CAD or reference documentation as well.

Contact

Use “Quick3D Viewer” in the subject and include:

  • App version, device model and iOS/iPadOS version
  • File format and steps to reproduce the issue
  • Any error message or a screenshot you can safely share

moriki.engineering@gmail.com

You do not need to attach confidential drawings or personal information in an initial inquiry. If a sample file is needed, discuss a reproducible example that you have permission to share.
