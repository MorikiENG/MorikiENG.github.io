Quick2D Viewer

図面を見る。気づきを残す。

PDF・DXF・DWGの2D図面を、iPhone・iPadで手軽に確認。番号付きコメントピンで気づきを残し、コメント付きPDFとして共有できる、Quick3D Viewerの姉妹アプリです。

DRAWINGS / COMMENTS / PDF2D.

PDF / DXF / DWG

01 / OVERVIEW

図面の確認から、
コメントの共有まで。

製造現場や打ち合わせ、外出先で図面を確認したいときに。Quick2D Viewerは、2D図面の閲覧と、図面上に残したコメントの共有をひとつにつなぎます。

  1. 01 / OPEN

    開く

    PDF・DXF・DWGを取り込み、拡大・縮小や移動で必要な箇所を確認。

  2. 02 / COMMENT

    残す

    気になる箇所に番号付きコメントピンを追加。あとから編集・削除もできます。

  3. 03 / SHARE

    共有する

    図面上の番号とコメント一覧をまとめたPDFを書き出し、iOSの共有画面へ。

02 / FEATURES

図面とコメントを、ひとつの流れで。

図面を見渡す

ピンチで拡大・縮小、ドラッグで移動。「全体表示」で図面を見渡せます。PDFは複数ページの切り替え、CAD図面はレイヤーの切り替えに対応します。

位置と一緒に、気づきを残す

コメントピンは図面やPDFのページ上に配置します。番号と本文を保存し、アプリ内に保存された同じ文書を再度開いて確認できます。

番号と一覧をPDFで渡す

図面上のコメント番号と、番号・ページ・本文の一覧を含むPDFを作成。共有先はiOSの共有画面で選択できます。

元の図面を変更しない

取り込んだ図面のコピーとコメントを端末内で扱います。元のPDF・DXF・DWGを書き換えずに、確認とコメントの記録ができます。

03 / FILE FORMATS

PDF・DXF・DWGに対応。

PDF

複数ページの図面を閲覧し、ページごとにコメントピンを配置できます。

DXF

ASCII（テキスト）DXFの2Dモデル空間を表示。バイナリDXFは対象外です。

DWG

R11/R12、R14、2000・2004・2007・2010・2013・2018保存形式に対応。R13や未知の保存形式は対象外です。

CAD図面はモデル空間の限定表示です。ハッチング、外部参照、CADフォント、寸法などに制限があり、完全な再現を保証するものではありません。

対応範囲・CADの表示制限を詳しく見る →

04 / SHARING

伝えたい場所を、番号で共有。

番号付きのピンとコメント一覧をひとつのPDFにまとめることで、図面のどこについて話しているのかを共有できます。元がPDFの場合は全ページ、DXF・DWGは表示中のレイヤーをモデル空間1ページに収めて書き出します。

共有PDFは閲覧・伝達用です。コメントデータの端末間同期や再編集用の移行形式ではありません。CAD出力の実寸印刷・製造用の縮尺は保証しません。図面形状の編集・寸法測定の機能はありません。
